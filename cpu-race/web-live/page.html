ยังไม่ได้เชื่อมต่อกับบอร์ด

  1. ต่อสาย micro-USB จากบอร์ด Nexys A7 เข้าคอม (เส้นเดียวกับที่ใช้โหลด bitstream) แล้วเปิดสวิตช์บอร์ด
  2. บอร์ดต้องมี bitstream รุ่นที่มี UART (build หลังวันที่ 2 พ.ย. 2569: fpga\run.bat top program)
  3. เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอม (Firefox / Safari / มือถือ ยังไม่รองรับ Web Serial)
  4. กด เชื่อมต่อบอร์ด แล้วเลือกพอร์ตที่ชื่อมี USB Serial / FTDI / Digilent (ถ้ามีสองพอร์ตให้ลองตัวที่เลขมากกว่า)

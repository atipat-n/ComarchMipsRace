Machine code

เลข 32 bit หนึ่งตัว มองได้หลายแบบ

รับ 42, -5, 0x2A, 0b101010 · คลิกที่ bit เพื่อสลับ 0/1 · bit 31 (ขีดแดง) คือบิตเครื่องหมาย

ถอดรหัสคำสั่ง

sign-extend 16 → 32 bit

immediate ของ addi / lw / sw / beq มีแค่ 16 bit ก่อนใช้ต้องขยายเป็น 32 bit โดยก๊อปบิตเครื่องหมาย (bit 15) ไปเติมด้านซ้าย
